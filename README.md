# AquaGuard AI Assessment Center

Drop-in CSV upload and project assessment module for AquaGuard AI.

## Includes

- Multi-file CSV upload
- Water assessment
- Wildfire assessment
- Landslide assessment
- Urban flooding assessment
- River/flash flood assessment
- Drought/water-stress assessment
- Extreme heat assessment
- Coastal flooding assessment
- Storm/cyclone assessment
- General project datasets
- Data-quality statistics
- Descriptive statistics
- Latitude/longitude mapping
- Project context using country, climate division, scenario and horizon
- Multi-hazard comparison
- Downloadable assessment CSV files

## Integration

Read `INTEGRATION.md`.

## Important

The screening scores are transparent prototype proxies. They are not official
CHRI or regulatory scores. For professional use, calibrate each hazard with
validated data, units, thresholds and expert-reviewed models.
